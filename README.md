# skills

Agent skills for Claude Code.

| Skill | What it does |
|---|---|
| [excalidraw-diagram](excalidraw-diagram/) | Generates a new Excalidraw diagram from a description or a codebase (C4, system block model, technical diagrams), with an offline render-and-review loop. |

Install: copy a skill directory into `~/.claude/skills/` or a project's `.claude/skills/`.
