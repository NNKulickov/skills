# task-sources - мапа источников задач

Читается на шаге 0 для резолва тикета (Spec-источник). Ключ - пара `host + repo`. Если пары нет -
**спроси у пользователя** источник и правило извлечения id, затем допиши запись сюда (часть
самообучения).

Поля:
- `type` - `youtrack` | `github-issues` | `jira` | `linear` | `none`
- `fetch` - как получить тикет по id (MCP-инструмент, CLI-команда)
- `id_rule` - как достать id (обычно regex по имени ветки или заголовку MR/PR); если ветки бывают
  в нижнем регистре - укажи, что id приводится к верхнему
- `notes` - (опц.) адрес трекера, особенности: тикеты без описания, нужен ли env для CLI, где
  лежат Standards, если в репо нет `CLAUDE.md`

Если `type: none` - тикета нет, Spec берём из описания MR/PR.
