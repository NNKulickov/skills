# Excalidraw Diagram Skill

A coding agent skill that generates beautiful and practical Excalidraw diagrams from natural language descriptions. Not just boxes-and-arrows - diagrams that **argue visually**.

Compatible with any coding agent that supports skills. For agents that read from `.claude/skills/` (like [Claude Code](https://docs.anthropic.com/en/docs/claude-code) and [OpenCode](https://github.com/nicepkg/OpenCode)), just drop it in and go.

## What Makes This Different

- **Diagrams that argue, not display.** Every shape/group of shapes mirrors the concept it represents - fan-outs for one-to-many, timelines for sequences, convergence for aggregation. No uniform card grids.
- **Evidence artifacts.** As an example, technical diagrams include real code snippets and actual JSON payloads.
- **Built-in visual validation.** A Playwright-based render pipeline lets the agent see its own output, catch layout issues (overlapping text, misaligned arrows, unbalanced spacing), and fix them in a loop before delivering.
- **Brand-customizable.** All colors and brand styles live in a single file (`references/color-palette.md`). Swap it out and every diagram follows your palette.

## Installation

Clone or download this repo, then copy it into your project's `.claude/skills/` directory:

```bash
git clone https://github.com/NNKulickov/skills.git
cp -r skills/excalidraw-diagram .claude/skills/excalidraw-diagram
```

## Setup

The skill includes a render pipeline that lets the agent visually validate its diagrams. There are two ways to set it up:

**Option A: Ask your coding agent (easiest)**

Just tell your agent: *"Set up the Excalidraw diagram skill renderer by following the instructions in SKILL.md."* It will run the commands for you.

**Option B: Manual**

Run the commands from the *First-Time Setup* section of `SKILL.md` (kept there so the agent
has them at hand mid-render; not duplicated here to avoid the two copies drifting apart).

## Usage

Ask your coding agent to create a diagram:

> "Create an Excalidraw diagram showing how the AG-UI protocol streams events from an AI agent to a frontend UI"

The skill handles the rest - concept mapping, layout, JSON generation, rendering, and visual validation.

## Customize Colors

Edit `references/color-palette.md` to match your brand. Everything else in the skill is universal design methodology.

## Language

Everything is in English except `references/system-block-model.md`, which is written in
Russian by design; its own file header documents the reasoning behind the mode itself.
When editing that file specifically, keep it in Russian; every other file in the skill
stays English.

## File Structure

```
excalidraw-diagram/
  SKILL.md                          # Design methodology + workflow
  references/
    color-palette.md                # Brand colors (edit this to customize)
    visual-patterns.md              # Pattern library, shape meaning, layout principles
    system-block-model.md           # Canon for the System Block Model notation (RU)
    c4-model.md                     # Canon for the C4 notation: levels, sheets, coverage
    technical-diagrams.md           # Evidence artifacts + multi-zoom, for Comprehensive/Technical mode
    merging-sheets.md               # Mechanics for merging several finished sheets into one file
    quality-checklist.md            # Severity-scored check before calling a diagram done
    element-templates.md            # JSON templates for each element type
    json-schema.md                  # Excalidraw JSON format reference
    render_excalidraw.py            # Render .excalidraw to PNG
    render_template.html            # Browser template for rendering
    pyproject.toml                  # Python dependencies (playwright)
    .venv/                          # Generated by `uv sync`, not part of the bundle, not portable
    vendor/
      excalidraw.bundle.js          # Self-contained Excalidraw build (offline rendering)
      fonts/                        # Excalifont & co, loaded via EXCALIDRAW_ASSET_PATH
      build-bundle.sh               # Rebuild/upgrade the bundle (needs node and npm)
```

## Model and Effort

`SKILL.md` frontmatter deliberately does not set `model` or `effort`. This work is
hand-authored coordinate JSON plus visual judgment calls on a rendered PNG - not a
mechanical, checklist-shaped task a small model can reliably do at low effort. Pinning a
specific model or a low effort level here would trade quality for a marginal cost saving
on a skill that is invoked occasionally, not in a hot loop. The decision is to keep both
values inherited from the invoking session, so the skill always runs at whatever
model/effort the user already chose for the conversation - explicit, not an oversight.

## Local Modifications

This copy is a fork of [coleam00/excalidraw-diagram-skill](https://github.com/coleam00/excalidraw-diagram-skill) and differs from upstream in two ways:

- **Offline rendering.** Upstream imports `@excalidraw/excalidraw` from esm.sh at render
  time. As of 2026-08-01 that build 404s on a transitive dep (`@braintree/sanitize-url`),
  and any CDN import means the renderer needs network on every run. The library is now
  vendored in `references/vendor/` (bundled from npm, so the upstream CDN state no longer
  matters either way).
- **Localhost HTTP server.** ES modules can't be loaded over `file://` (CORS), so
  `render_excalidraw.py` serves `references/` on an ephemeral `127.0.0.1` port while rendering.
